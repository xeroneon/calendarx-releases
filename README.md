# CalendarX Releases

Public distribution channel for **CalendarX** — a self-hosted, CalDAV-generic
calendar + tasks client.

## What's here
Signed Android APKs (Capacitor hybrid wrapper), published by CI from the private
source repo [xeroneon/calendarx](https://github.com/xeroneon/calendarx). The
source repo stays private; this public channel is what any client pulls from.

## Install with Obtainium
1. Add a new app in Obtainium.
2. **Source:** GitHub — `xeroneon/calendarx-releases`
3. **What to install:** `calendarx-v[.\d]+.apk`
4. **Version check:** By release tag name
5. Disabled *prereleases* (default) so unreleased/transition builds are skipped.

## Releases
Each GitHub Release here carries one asset: `calendarx-v<version>.apk`,
signed with the CalendarX release keystore (`applicationId dev.calendarx.app`).
See the release title/notes for the version.
